# Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option for this repository:

<https://github.com/pete-lgtm/astra-panel/security/advisories/new>

Include the affected version, steps to reproduce using synthetic data, and the
impact. Do not publish credentials, private site data or exploitable details in
a public issue. Never test against another person's panel or equipment.

The project is a prototype. Fixes target the latest source on `main`; there is
no maintenance commitment for older snapshots. A working web server or health
report alone does not establish that an alarm installation is operational.
